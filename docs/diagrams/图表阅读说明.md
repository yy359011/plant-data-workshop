文件使用方式：

- `.drawio` 是原生可编辑源文件；全集包含全部 8 页。
- `.png` 是清晰预览，适合离线 HTML 与直接阅读。
- `.svg` 内嵌可编辑图表数据，可由 draw.io 继续编辑。
- 全集 `.pdf` 是 8 页图片阅读版，便于逐页阅读、分享或打印；编辑请使用配套 `.drawio` 或 `.svg`。
- `manifest.json` 提供图表清单；`index.html` 是离线阅读导航。

图表中的标题、卡片、文字、编号和连线均为原生 draw.io 单元。Image2 只用于构图参考，未嵌入最终图。字体采用 PingFang SC；其他电脑可替换为系统中文无衬线字体。

当前功能边界：平台生成训练数据，不执行大模型训练；外部 API 数据源只登记，尚未自动同步；OCR 与章节模型使用实际配置的接口；知识库为关键词检索；抽检样本通过率不能推断整批准确率；账号只有管理员、所内研究人员、所外研究人员三个内置角色。授权标签须依据实际资料权利填写，系统不自动判断版权或模型服务条款。
