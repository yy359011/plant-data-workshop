# 植物科研数据工坊 · Windows 源码开发包

解压整个目录到电脑上的可写路径，双击 **start-dev.cmd**。

第一次运行前，请安装 Python 3.10+ 和 Node.js 22.13.0+（包含 npm）；脚本会检测环境，再自动安装项目依赖。首次安装依赖需要网络，安装完成后可本地开发。

启动成功会自动打开 http://127.0.0.1:5173 。其他局域网电脑访问控制台显示的 IP:5173。首次管理员请在运行服务的电脑创建。

这是 React/Vite 源码热更新 + Python 后端，不需要 Nginx、不依赖生产构建或 dist。修改 src/ 会立即更新页面；修改 Python 后重启脚本。按 Ctrl-C 停止。

- **DEV-WINDOWS.md**：完整环境、启动、端口与故障处理。
- **docs/diagrams/index.html**：离线图表导航，可放大查看全部功能与模块操作流程。
- **docs/功能模块与交接索引.md**：逐模块操作与源码文件入口。
- **APP-MANUAL.md**：平台功能使用说明；其预构建启动命令不适用于本源码交付包。

包内含初始植物学资料与历史产物，未包含正式账号、登录会话、保存的模型/OCR密钥或本次功能验收操作。开发数据保存在本包的 data/ 目录，与原电脑正式工作空间独立。
